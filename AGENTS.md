# Production releases

Every change package uploaded to production branch `main` must increase the application version. Never upload another production change under the same version. Keep the root version in `package.json` and `package-lock.json` aligned; the UI version and build date are generated by Vite. Preserve historical release notes and dependency versions.

Before committing a release, run the full unit suite (`npm test`), full iPhone/iPad E2E suite (`npm run test:e2e`) against a current production build (`npm run build`). Preserve legacy IndexedDB records and full internal calculation precision.
